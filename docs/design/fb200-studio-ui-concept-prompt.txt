Use case: ui-mockup
Asset type: High fidelity redesign mockup for FB200 Studio, a Flutter multi-effects editor for a bass guitar hardware pedal.
Primary request: Create a convincingly shippable, practical professional music-equipment application interface inspired by the clear signal-flow workflow of Neural DSP Quad Cortex, with original FB200 visual identity. This is an actual flat application screenshot, not a marketing poster or physical pedal rendering.
Composition/framing: One single landscape tablet/desktop app screen, approximately 16:10, front-on edge-to-edge interface, no device bezel, no surrounding scenery, no annotations outside the app. Carefully aligned pixel-clean UI with a restrained high-end industrial design. Large legible controls with generous touch targets, minimal nesting.
Style/medium: Precise polished Flutter UI design. Near-black charcoal workspace, slightly lighter graphite panels, thin quiet separators, crisp off-white sans-serif typography, tabular numeric readouts. Use small restrained accents by effect category: gate gray-blue, comp amber, amp warm orange, cab sand, EQ green, modulation cyan, delay blue, reverb violet. No glowing neon, glassmorphism, cartoon hardware, unnecessary gradients, fake 3D chrome knobs, or giant whitespace.
Layout:
1. Slim top application bar: brand "FB200 STUDIO", green dot and "USB CONNECTED", small settings icon.
2. Narrow left preset browser taking about 17% of width, titled "PRESETS". Search field. Clean numbered list of bass presets. Highlight "07  Studio Finger". Other items: "05  Warm Clean", "06  Vintage Round", "08  Modern Slap", "09  Pick Drive", "10  Ambient Bass". Footer "40 PRESETS".
3. Main workspace header prominently shows "07" and "Studio Finger", a small amber "EDITED" indicator, previous/next preset arrows, and an obvious "SAVE" button.
4. Signal flow panel directly below header. Title "SIGNAL CHAIN", subtle helper "FIXED ORDER". Show one unambiguous continuous left-to-right serial signal wire with arrow direction, from an "IN" endpoint through exactly eight equally aligned selectable effect tiles to an "OUT" endpoint. Exact order: "GATE", "COMP", "AMP", "CAB", "EQ", "MOD", "DELAY", "REVERB". No parallel routing, no branching, no unused slots, no reorder affordances. Each tile has a simple original effect glyph, effect category name, and small "ON" or "OFF" status. Selected AMP tile has a warm orange border and brighter panel. MOD and DELAY are OFF and muted but remain legible and connected by the wire. Others ON. Avoid duplicate tiles or disconnected wire fragments.
5. Main lower editor panel is large and spacious, titled "AMP" and model dropdown "Ampog SVT4". A clear power toggle reads "ON". Give this panel real visual prominence. Two clean rows of parameter controls, four across then three across. Modern flat arc knobs, not physical knobs. Labels and matching values exactly: "GAIN" "38", "BASS" "52", "MID" "46", "TREBLE" "58"; second row "MID FREQ" with a segmented selector "200 Hz", "400 Hz", "800 Hz", "1.6 kHz", "3 kHz" where "800 Hz" is selected, "VOLUME" "70". Arrange the second row comfortably rather than forcing the frequency selector into a knob. All continuous amp values are 0-100. Each continuous parameter has a thin arc, a value readout that looks directly editable, and enough finger space. Small helper inside panel "Select a block to edit its parameters".
6. Bottom utility strip with obvious compact buttons "TUNER", "DRUMS", "IR LIBRARY"; output control on the right "OUTPUT" "-6 dB" with a slim horizontal slider and "MUTE". A small "ASSISTANT" button is present as a collapsed secondary tool, not an open chat column. Keep the editor as the focus.
Constraints: All English labels above must be spelled exactly. Strong readable hierarchy and contrast, musician-first workflow, consistent control spacing. Show only the capabilities described. No scene switcher, looper, neural capture, cloud library, performance meters or fabricated waveforms. Do not put Neural DSP or Quad Cortex logos or names in the rendered UI. Not a website landing page. Not a generic admin dashboard. One coherent app screenshot, no collage.
